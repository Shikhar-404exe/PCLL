# AI Recommendations Feature - User Guide

## Overview

The PCLL app now includes AI-powered recommendations that provide personalized action suggestions based on your current Cognitive Unit (CU) balance and cognitive state.

## Features

### What It Does

- Analyzes your current CU balance and cognitive state
- Generates 3-5 specific, actionable recommendations
- Considers your recent 7-day patterns and trends
- Provides context-aware advice for managing cognitive load

### How to Use

1. **Location**: The recommendations card appears on the home screen under the "RECOMMENDATIONS" section

2. **Expand/Collapse**: Tap the card header to show or hide recommendations

3. **Refresh**: Use the refresh icon (🔄) to get new recommendations based on your current state

4. **AI Mode vs Fallback**:
   - **With API Key**: Recommendations are generated by Azure OpenAI with personalized, context-aware advice
   - **Without API Key**: Smart rule-based recommendations are provided based on your CU level

## Setup for AI-Powered Recommendations

### Configure Azure OpenAI (Optional)

1. Open the `.env` file in the `pcll_flutter` directory

2. Add your Azure OpenAI credentials:

   ```env
   AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
   AZURE_OPENAI_DEPLOYMENT=gpt-4
   AZURE_OPENAI_API_KEY=your_actual_api_key_here
   AZURE_INSIGHTS_ENABLED=true
   ```

3. Restart the app to apply changes

### Without Azure OpenAI

The app works perfectly fine without Azure OpenAI! It will automatically use intelligent rule-based recommendations that adapt to your CU level:

- **High Capacity (>80 CU)**: Suggestions for tackling challenging work
- **Good Capacity (60-80 CU)**: Balanced approach with medium tasks
- **Moderate (40-60 CU)**: Focus on routine work and breaks
- **Low Capacity (20-40 CU)**: Recovery-focused recommendations
- **Critical (<20 CU)**: Urgent rest suggestions
- **Deficit (<0 CU)**: Essential recovery actions

## Recommendation Examples

### AI-Powered (with API key)

- "Take a 10-minute walk outside to refresh your mind"
- "Break your next complex task into 3 smaller, manageable chunks"
- "Schedule a 5-minute breathing exercise before your next meeting"
- "Consider postponing non-urgent decisions until tomorrow when your CU is higher"

### Rule-Based (without API key)

- "Great energy! Tackle your most challenging task now"
- "You're running low - prioritize rest and recovery"
- "⚠️ Critical low energy - immediate rest needed"

## Benefits

1. **Personalized**: Takes into account YOUR specific CU balance and patterns
2. **Actionable**: Provides concrete steps you can take immediately
3. **Adaptive**: Changes based on your current state
4. **Smart Fallback**: Works without AI integration
5. **Privacy-Focused**: Only sends anonymized CU data if you configure Azure

## Tips

- Check recommendations when planning your day
- Refresh after completing a major task to get updated suggestions
- Use recommendations as guidance, not strict rules
- Pay attention to patterns in what works for you

## Privacy & Data

- Your personal data never leaves your device unless you configure Azure OpenAI
- When using Azure AI, only your CU balance, state, and recent trends are sent
- No personal identifiers are included in AI requests
- You can disable AI features anytime by setting `AZURE_INSIGHTS_ENABLED=false`

---

**Note**: The recommendations feature is designed to help you make better decisions about managing your cognitive load. It's a tool to support your judgment, not replace it.
